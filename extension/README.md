# TruthLens Chrome Browser Extension (Manifest V3)

Verify factual claims, detect fake news, and inspect evidence directly on any webpage.

## Installation Instructions

1. Open Google Chrome (or any Chromium browser like Brave, Edge).
2. Navigate to `chrome://extensions/`.
3. Toggle on **Developer mode** in the top right corner.
4. Click **Load unpacked**.
5. Select the `p:\TruthLens\extension` folder.
6. The TruthLens extension icon will appear in your browser toolbar!

## How to Use

### 1. Context Menu Verification (Inline Highlight)
- Highlight any claim or text on any web article or social post.
- Right-click $\rightarrow$ Select **"Verify with TruthLens"**.
- A sleek floating verification badge appears in the bottom right corner showing the verdict, confidence score, and explanation.

### 2. Toolbar Popup
- Click the TruthLens shield icon in your extensions toolbar.
- Type or paste a statement $\rightarrow$ click **"Verify Claim"**.
- Click **"Open Full Investigation & Evidence Trail"** to view the full dashboard at `http://localhost:5173`.
